# SIFT social kit

## Bio

Small agents. Clear signals. SIFT turns public code changes into source-linked reports. Collect. Inspect. Publish. Every job leaves a trail.

## Post 1 - Meet SIFT

Meet the team behind the signal.

SIFT puts three observation agents on public code repositories. Pip collects the latest revision. Dot classifies the changed files. Bit publishes a report with the original source and a checksum of its inputs.

Every run has a record. Every report has a source.

The work doesn't disappear behind a spinner.

## Product facts

Agents are deterministic server-side workers, not LLMs or autonomous developers. They analyze returned metadata, do not execute repository code and do not certify security. Production checks are scheduled every ten minutes and can be delayed by failures or provider limits. Initial baselines and capped file coverage are labeled. Source controls require operator access. Reports and connected sources are public. The token watcher is separate, requires an explicitly configured public developer wallet, and never moves funds. Videos illustrate the workflow, not evidence of a particular run. No partnerships, returns, payments or trading activity are implied.
