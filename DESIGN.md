# SIFT design direction

An open, light workroom occupied by three distinct pixel agents. The real object is a repository change report, not a balance screen. Scanner, classification desk and little printing press carry the visual identity.

Colors: paper #f4f6f8, ink #20262c, cobalt #3265e8, coral #e87169, yellow #f2ce59, mist #cbd8dc. White/light neutral dominates; no dark dashboard, cream wash, gradients or floating page-section cards.

Type: Silkscreen for the SIFT name and compact section titles. IBM Plex Mono for working copy and records. Fixed sizes, zero tracking. Actions are compact icon-plus-text commands; modes use tabs.

Layout: horizontal masthead, large unframed pixel workbench, a three-stage progress strip, then run history beside the actual report. The rail-based garage was rejected: this needs a horizontal production line and a tangible document output. Mobile collapses to one continuous page, with all three stages still visible.

Motion: an opening scanner assembles the SIFT mark from tiles. Agents blink at rest; machinery animates only for current persisted stages or a clearly labeled replay of an actual run. No fabricated jobs, timestamps, transaction volumes, payments or typing indicators.

Visual QA: desktop/mobile, reduced motion, actual canvas pixels, buttons, tabs, evidence URLs and empty/error states. Public GitHub source link, token monitor and wallet remain distinct from the monitored code repositories.
